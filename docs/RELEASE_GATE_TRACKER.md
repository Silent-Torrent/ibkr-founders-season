## 怎么理解“还剩多少”

本表把 [MVP_BACKLOG.md](../MVP_BACKLOG.md) 的 P0 在建立时的 **12 项未关闭门槛**固定编号，方便每次工作结束逐项核对。基线分类为设备与测试收尾 8 项、财务来源 1 项、部署 3 项；2026-09-09 分别关闭 D05、D04、D03 后，当前剩余 **9 项：设备与测试收尾 5、财务来源 1、部署 3**。此前 D03 键盘复测为 10 → 9；本轮 0.24 候选 L01 短横屏修复为 **9 → 9**，建立后累计仍为 12 → 9。L01 是 D08 内部相关问题，不人为新增第 13 项；编号不因排序或完成情况改变。

这不是 12 个工时相同的任务，也不是整个产品一生的待办清单；不能由数量推算完成百分比、还需几天或未经验证的上线日期。某项可以部分推进而仍未关闭；实测发现新问题时，剩余工作也可能增加。

- 本表只追踪现有 P0，不新增或降低产品、浏览器、隐私及上线要求；原待办与证据记录仍是核对来源。初始映射行号仅用于定位 `482c66d` 基线，后续以编号和项目名称对应。
- `OPEN` 表示尚缺关闭证据；只有实际范围全部通过、有可追溯记录并同步原待办后，才能改为 `CLOSED`。旧版本、另一设备或桌面模拟通过，不能直接当作当前目标通过。已关闭项如回归，沿用原编号重新打开。
- 初始状态为 12 项 OPEN、0 项 CLOSED；2026-09-09 的 0.23、iPhone 15 Plus / iOS 27.0 HTTP 三语观察关闭 D05，简体原生复制按 `USER_CONFIRMED` 及独立收尾关闭 D04，后续三语真实镜像转发键盘回焦关闭 D03。当前 **9 项 OPEN、3 项 CLOSED**，D07 完整 VoiceOver 仍开放。这些已关闭项的原资产和证据范围不变。最新源码是从 `891fc36` 开始的 0.24 候选；独立输出只变 CSS 字节，12 组非浏览器检查及完整独立包浏览器回归均已通过。电脑测试监听/临时输出已清理，但手机仍使用旧 0.23：四主页面简体旋转已获 `USER_CONFIRMED`，不是主线独立观察；引导页/打开面板、旧轮收尾和 0.24 复测仍待完成，原服务为下一组保持可用；不把电脑或旧 D03 当轮收尾写成手机本轮已结束。每次更新需注明日期、版本、设备/环境、证据来源及文件，不把用户确认写成开发方直接观察。
- D06 是旧测试文件定位与收尾，不是产品功能；P1/P2 的历史存储、新徽章、反馈/分析、账户、后台、正式排行榜等，以及上线后的持续维护，都不包含在这 12 项中。
- 本地交付、获准部署、实际上线是不同阶段。L 部署冻结仍有效；即使本地测试完成，也不能自动授权外部上传或公开上线。12 项数量归零本身也不能替代届时的上线授权和完整发布复核。

## 每次 session 结束的固定通报

每次结束都用下面的普通中文结构报告，无实质变更也照实写“未减少”；不将计划、测试开始或生成文件当成完成。

1. **本轮完成**：列出实际完成的改动/验收/清理及直接证据；未通过或只完成部分的，另外说明。
2. **还剩多少**：本轮开始 `x` 项 → 结束 `y` 项；设备/测试收尾 `d`、财务来源 `f`、部署 `r`。列出关闭或重开的稳定编号；若有新问题，单独给问题编号与影响，说明是否阻断原门槛，不悄悄删改基线 12 项。
3. **当前版本与测试范围**：checkpoint/提交、生产构建、实际设备与系统、桌面或真机、HTTP 或 HTTPS；明确哪些结果不能互相替代。
4. **下一步需要你参与什么**：只列下一轮必须的操作或决策；其余开发方继续完成。没有需要参与的事项也直说。
5. **交付与上线状态**：本地可交付范围、尚缺证据，以及 L 部署冻结是否仍有效；如已改变，引用用户的新决定。不给无证据的完工百分比或上线日期。

更新规则：按当轮实际证据核对 [MVP_BACKLOG.md](../MVP_BACKLOG.md)、[WORK_HANDOFF.md](../WORK_HANDOFF.md) 与 [VERIFICATION.md](../VERIFICATION.md)，同步状态后再报数。单个门槛内部完成了部分步骤但仍缺关键证据时，保持 `OPEN` 并报告部分进展，不拆小项目制造下降。
