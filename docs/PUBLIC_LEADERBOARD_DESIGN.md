# 公开赛季榜 · 待 Philip 审批的设计

当前应用继续离线解析。仅当负责人批准数据字段、地区、预算和退出机制后，才另开服务端实现 PR。第一阶段建议只接收自报成绩，不设现金奖品。

## 从预览到公开

保留静态 SPA 和现有 CSP。未来用独立 Vercel 项目承载榜单域名，静态应用仅在用户主动打开榜单后交接；不在导入时发送任何请求。用户可手动复制最小成绩包，在新页面看到公开样张。写入前，显式选择赛季、查看字段、勾选单独的公开同意，保存私有撤回密钥。演示和测试报表拒绝参赛；客户端可以伪造来源，因此仅标 Self-Reported。

榜单服务验证字段白名单、拒绝额外字段和过大请求。Vercel Function 对参数化 Postgres 事务做写入；只读接口分页读取公开视图，按赛季、组别、来源筛选，收益率并列共享名次。写接口限同源、限速、幂等；读取端缓存最多 60 秒，退出时主动失效。数据库服务商、区域、备份与日志保留期须另行确认。

| 存储位置 | 字段白名单与用途 |
|---|---|
| 公开 entry | 随机参赛 ID、系统生成昵称、自然年、截止日、五档分组、按基点取整的赛季收益率、最多三个合法勋章 ID、来源类型及计算规则版本 |
| 私有控制 | 随机管理密钥摘要、同意文本版本、同意时间、更新时间、审核状态。每个参赛记录每季一行，重复提交覆盖，旧快照不累加 |
| 举报工单 | 工单 ID、参赛 ID、枚举理由、处理时间和裁定。初版不接收自由文本、附件或联系方式 |
| 短期限流 | 每日轮换密钥生成的请求来源摘要、窗口计数、到期时间；24 小时删除。代理与平台日志单独审查 |

不接收金额、账户号、代码、交易明细、文件名、原报表及经纪商凭据。服务端随机参赛 ID 无法证明一个人或一个账户只提交一次。使用本地撤回密钥可立即隐藏条目、删除主库记录、清除缓存。丢失密钥走人工核验，核验前可先隐藏争议记录。建议赛季结束 90 天删除条目，备份 30 天滚动到期；恢复时先重放删除清单，避免复活。须向用户说明第三方截图及转发无法收回。

## 可信度与滥用处理

自报榜和券商来源榜分池。校验截止日、百分比精度、有效分组、勋章白名单；极端收益进入人工审核，不以收益率高低自动认定作弊。拒绝同一密钥回放旧快照。虚假成绩、批量注册和刷榜先限流、隐藏、记录理由，再允许持密钥申诉，由第二位审核者复核。系统生成昵称可降低冒充和广告风险。无私信或外链。紧急开关可停止写入、隐藏榜单并保持本地产品可用。

可选券商来源另立审批项。Flex Web Service 使用用户配置的 Query ID 与报告 token，可按查询设置触及多个关联账户。不能把自报 CSV、对战码校验和或成功连接当作 Verified。先征得 IBKR 对第三方用途的许可，验证可限单账户、只读、限制返回字段及日志脱敏。提议一次性拉取，凭据与原始响应只存在隔离进程内存，禁止记录请求 URL；重算同一自然年 YTD 收益率与分级后只输出上表字段。拒绝多账户、部分周期、缺失收益率和核对失败。未来持续同步涉及长期凭据托管，须单独批准加密、轮换、撤销及删除演练。停用时取消同步并提示在 Client Portal 撤销 token。若无法保证限定范围，则仅提供自报榜。

## 隐私、法律与成本决策

即使删除金额，收益率加分组仍会泄露财富区间。稀有勋章、截止日组合也可能识别个人。建议默认关闭发布，提供省略勋章的选择，小分组少于十条时不展示分组榜。上线前按实际服务地区审查金融营销、未成年人、隐私权利请求、跨境处理和供应商协议。免责声明不能替代这项审查。平台访问日志可能处理 IP，须查清实际字段、地域和保留时间后再向用户承诺。

| 方案 | 预算与范围 |
|---|---|
| Hobby | 官方标价每月 0 美元，限个人非商业用途，有用量上限。仅考虑非商业封闭验证；外部数据库可能独立计费 |
| Pro | 单个付费席位起价每月 20 美元，含 20 美元基础设施用量额度。数据库、超额流量、函数计算、日志、备份和税费另计；公开商业用途应按实际席位和账单估算 |

例如每日 1,000 次查看、100 次更新，按 30 天有 30,000 次读取和 3,000 次写入，缓存命中可减少数据库读取。金额预算须结合页大小、实际 CPU 时间、数据库套餐与区域费率计算。建议先用压测获得单次成本，负责人设定支出上限和告警后再开放。先通过合成数据的删除、缓存失效、日志泄密、重复提交和滥用关停演练，再审批受保护预览。
