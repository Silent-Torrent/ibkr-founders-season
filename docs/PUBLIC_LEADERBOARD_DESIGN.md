# 自报赛季榜 · 负责人批复

**2026-11-03，Philip 已批准：自报榜 + 白名单 + Hobby 封闭内测。** 本阶段展示未经核验的成绩。公开访问、券商验证、付费套餐及跨境正式运营另行审批。

## 提交与退出

导入和计算继续在浏览器内完成。内测开关默认关闭。用户打开自报榜，预览将提交的全部字段、保存本机撤回凭证、单独勾选同意，再点击提交。仅这一步触发一次同源提交。禁用自动重试。查看分组和撤回分别由用户主动触发。撤回无需原始报表。撤回后重新读取立即反映变化，已保存的第三方截图无法收回。

| 允许上传的八个字段 | 约束 |
|---|---|
| 随机参赛 ID | 由高熵本机随机数派生，与券商身份无关 |
| 系统生成昵称 | 从参赛 ID 派生，服务端复算，无自由文本 |
| 自然年 | 榜单赛季 |
| 截止日 | 赛季内有效日，不能晚于当天 |
| 五档分组 | 只传分组枚举 |
| 赛季收益率 | 整数基点，100 基点等于 1% |
| 勋章 | 最多三枚不同的注册 ID |
| 来源类型 | 固定为自报 |

拒绝额外字段，包括金额、账户号、代码、明细、文件名、原报表及计算版本。撤回密钥不写入成绩记录。仅公示已通过审核的条目，按自然年和分组计算门槛，少于十条隐藏整个分组；平台无法证明十个随机 ID 对应十个自然人。没有全站搜索、自由昵称或个人详情。所有条目及待审记录在赛季结束后第 90 天到期。限流计数单独短期过期。

## 封闭内测架构

静态页面 + 同源 Vercel Functions + Marketplace 私有存储。浏览器仅与本站 /api/leaderboard 通信；存储密钥只进服务端环境。发布接口执行字段校验、原子限流、重复提交保护及极端值隔离。人工复核前不计入人数或排名。收到冒用或刷榜举报后负责人可隐藏或删除条目；紧急时停写，继续允许撤回。仅收益率无法判断造假。来源固定标注 Self-Reported。券商同步另见独立研究，尚无 IBKR 第三方许可。

## 托管与预算

Hobby 用于非商业封闭内测。负责人在 Security / Deployment Protection 启用 Vercel Authentication 的 **All Deployments**，覆盖预览、生产别名和自定义域，禁用公开例外。匿名分别访问页面、读 API、写 API 都须被拒绝才能启用写入。Vercel 于 2026-09-09 将该范围开放至所有套餐。[官方公告](https://vercel.com/changelog/protect-production-deployments-for-free-on-every-plan)

默认新增支出上限为每月 0 美元。使用 Hobby 与外部存储免费固定配额，关闭自动升级和按量付费；任何无法硬限制新增费用的配置均保持停写。供应商配额耗尽后拒绝请求，负责人核对账单和告警再决定是否扩容。Pro 另含席位、计算、带宽及单独的存储费用，须重新批准预算。不要把告警当成支出上限。[Vercel 定价](https://vercel.com/pricing) · [Upstash 定价](https://upstash.com/pricing/redis)

## 隐私与运营

分组暴露资产区间，稀有勋章、日期和回报组合仍可能重识别。默认关闭；在同意界面说明字段、可见范围、撤回与到期日。日志不得包含请求体、密钥、原始 IP 或异常详情。负责人配置供应商区域、日志和备份策略；条目删除后不得从备份恢复。无法满足保留期时不开写。内测前按实际参与地区审查数据跨境、权利请求、未成年人及金融宣传规则。自报成绩无现金奖项。公开上线需 Philip 单独批准。
