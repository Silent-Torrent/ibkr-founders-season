## 旧生产包反例：真实滚轮仍无法触达

主线对旧 0.23 生产包执行新回归，进程会话 `59368` 以退出码 `1` 失败。在英文 `812×300` 视口下，侧栏隐私入口的实际几何读数为：

| 指标 | 旧包实测 |
| --- | ---: |
| 入口 top / bottom | 481.14 / 496.14 px |
| 侧栏 scrollTop | 0 |
| 侧栏 scrollHeight / clientHeight | 573 / 300 px |
| `elementFromPoint` 命中入口 | false |
| 真实滚轮尝试 | 12 次后仍不可达 |

这不是“按钮是否存在于 DOM”的检查。入口在视口之外，真实滚轮无法使侧栏滚动，命中检测也不通过；旧包因此没有获得后续“点击成功”的假阳性。此前只做较高视口的宽度响应式检查，没有覆盖这个高度缺口。

## 最小修复与回归方法

[侧栏样式](../src/styles.css) 新增 `overflow-y: auto`、`overscroll-behavior-y: contain` 及直接子项 `flex-shrink: 0`。没有修改页面业务逻辑、财务口径、Worker、容量、持久化、依赖或部署设置。

[短横屏回归](../scripts/test-short-landscape.mjs) 接入 [生产浏览器测试](../scripts/test-browser-import.mjs)，在首次虚构 CSV 导入及 Ledger 基础断言之后执行，不使前面的文件输入节点引用失效。

- 三语分别覆盖 `812×300`、`812×375`、`932×375`，共 9 个横屏组合；每语另切回 `375×812`，共 3 个竖屏阶段。
- 横屏先用真实滚轮将侧栏归顶，再滚动到侧栏内部的隐私入口，要求实际 `scrollTop > 0`，且主页面没有代替侧栏滚动。
- 每个被测控件必须完整进入视口和容器边界，且 `elementFromPoint` 命中该控件或其子元素，才发送真实指针按下/释放。没有以隐藏底部入口或直接 DOM `.click()` 替代侧栏可达性。
- 四个导航都要发生真实页面切换，并同时核对当前导航与该页面独有内容；隐私入口要真正打开聚焦弹窗，关闭后回到原入口；侧栏指南要真正打开，再经可达的返回按钮保留当前虚构报表。
- 回到窄竖屏后，检查侧栏隐藏、底导航显示，四个底导航按钮均可实际点击，且没有页面横向溢出。
- 最后恢复调用前的语言、Ledger、视口及滚动状态，并核对报表未变。程序设置语言和最终恢复只属于测试准备/收尾，不计为真实可达性证据。

这些是桌面 Chromium 的真实滚轮/指针与视口证据，不是物理 iPhone 旋转、原生触摸或 iOS/Safari 16.4 证据。
