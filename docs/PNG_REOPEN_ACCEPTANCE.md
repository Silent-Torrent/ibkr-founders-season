# R02 分享图验收卡

R02 的负责人验收使用已获准、受保护的 HTTPS 预览和 Chrome 手机触控模拟。先记录部署对应的提交、Chrome 版本、操作系统、语言和视口。用内置演示或仓库虚构 CSV，分享金额保持默认关闭。

| 尺寸选项 | 完整文件名 | 重新打开后的尺寸 |
| --- | --- | --- |
| 默认 | `pnl-arena-2026-season.png` | 1200 × 1500 |
| Story | `pnl-arena-2026-season-story.png` | 1080 × 1920 |
| 3:4 | `pnl-arena-2026-season-3x4.png` | 1080 × 1440 |

1. 使用空的临时下载目录，避免浏览器为同名文件自动加序号。逐个选择尺寸并点击下载，等浏览器显示下载完成。
2. 从下载目录重新打开文件。核对完整文件名只有一个 `.png`，尺寸符合上表，整张图片能解码。图中保留虚构来源和非投资建议，品牌红条为斜切，默认看不到金额、账户号、精确净清算价值和持仓代码。
3. 记录各尺寸的完成、重开和内容结果。可附虚构卡片截图，截图前移除平台身份和认证信息。验收后清除测试副本。

本地 Product checks 从完成的下载读取 PNG，核对名称和 IHDR 后交给浏览器解码，再检查斜切条像素。`release-gate-evidence` 保留下载图、字节数与 SHA-256。这个 HTTP 对照供 HTTPS 验收比对。Safari 系统分享和实际文件保存属于独立范围。R02 保持 OPEN，关闭由 Philip 验收。
