# 对战码

在竞技场复制前查看将分享的收益率、段位、勋章 ID。粘贴对手的码可在本机比较自报成绩。码内没有账户号、金额、交易代码或报表。

PL1 使用 SHA-256 的前 12 个十六进制字符检查输入错误。算法没有签名密钥，任何人都能改写收益率后重新计算有效校验和。因此解码成功只说明格式和校验和一致，不能防伪，也不能验证成绩来源。

输入有效码后，竞技场并排显示双方收益率、资产组别和勋章。对手一侧标注自报、非券商验证。PL1 没有赛季或截止日，数字供娱乐对比。资产组别会透露账户规模区间，转发前请与对手确认。

点击「下载对战卡」在浏览器生成 1080 × 1440 PNG。卡片内容与预览相同，包括双方来源、收益率、资产组别、勋章及非投资建议。原码、金额、账户和持仓明细不进入图片。下载后的图片是独立副本。
