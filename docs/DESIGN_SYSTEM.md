# Founders Season · Wrapped 海报风

每页先回答一个问题。欢迎页和成绩页展示赛季收益与人格，勋章页展示点亮数量，竞技场展示名次，导入页突出 CSV 入口。桌面使用留白和双栏，390px 手机保留纵向阅读顺序，长中文和英文均允许换行。

| 用途 | 规则 |
|---|---|
| 画布与油墨 | 近黑 #0b0b0b、米白 #f4efe6、深灰 #3a3a3a。正文使用米白或浅灰，避免在品牌色上叠放浅色小字。 |
| 品牌红 | #ff2b2b 用于斜切边、印刷网点和章节标记。正负收益沿用用户选择的涨跌主题，并保留数值正负号。 |
| 字体 | Anton 用于海报级拉丁标题和关键数字，Space Grotesk 用于常规拉丁文本与数字，Noto Sans CJK SC 用于中文。三者自托管，许可为 SIL OFL 1.1。 |
| 导航与操作 | 顶部章节条随当前页面变化，故事内的分段条反映实际页数。主操作使用米白胶囊按钮；焦点环与键盘导航单独保留。 |
| 徽章与身份 | 金属徽章置于圆形底座。锁定与已获得状态保留文字。人格贴纸只显示规则命中的标签，并遵守吐槽开关。 |
| 财务语义 | 主数字沿用报表的赛季收益，缺失时显示不可用。金额与代码遵守现有展示范围；分享默认不含金额。示例名次有虚构来源标记。 |

纹理只用静态几何。不要模拟系统状态栏、自动播放动画或使用全站百分位。截图取自内置 demo，手机 390 × 844，桌面 1440 × 900。

Anton 与 Space Grotesk 来自 Fontsource 5.3.0 的 Latin WOFF2，随应用打包为二进制 FontFace，无需额外网络请求。许可证位于 public/fonts。中文沿用 src/assets/season-ui.woff 中的 Noto Sans CJK SC 子集及同目录 OFL 文件。

本机账本将金额、逐标的明细与核对数据放在原生折叠区，进入成绩页及更换报告时默认收起。展开仅影响当前视图，不会开启分享卡金额或新增存储。
